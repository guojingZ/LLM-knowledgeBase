知识元模型 · 三层架构全景图

场景层 → 概念层 → 实体层 · 两轮萃取驱动 · 面向场景组装

场景层 — 14 个场景

  • • 每个场景 = 一个"如何…"的问题
  • • composition 按 phase 组装概念和实体
  • • trigger 描述触发条件，goal 描述产出目标
  • • 场景是面向用户的最终交付界面

概念层 — 30+ 概念 · 8种类型

  • • 每个概念有 define ≤50字 + IPO或decomposition
  • • type: 思维方法/认知原理/分析操作/知识管理等
  • • relations: 通过8种精确关系互相关联
  • • 无IPO无decomposition → 不独立存在

实体层 — 20+ 实体 · 5大分类

  • • category × type 双维度分类
  • • children 嵌套最多3层
  • • 至少1个relations条目才能收录
  • • 边界判据: 能说"用了XX"且XX非思维动作
