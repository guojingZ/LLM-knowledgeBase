# 未来 Skill 设计草案

## 当前状态

Pending verification。当前不安装、不发布 Skill。

## 未来职责

稳定后的知识应用 Skill 只规定：何时调用知识工具、候选不清时如何澄清、如何引用证据、何时拒答、如何记录反馈。它不保存正式知识，也不复制 Python 业务逻辑。

## 进入 Skill 阶段的条件

1. 种子问题集经过人工确认；
2. 模型导航相对 Raw baseline 的收益得到验证；
3. 错误能够区分为知识、检索、回答或边界问题；
4. 本地命令和输入输出合同稳定；
5. 至少完成一次应用反馈驱动的增量知识更新。

满足后，先包装 stdio MCP，再制作薄 Skill。
