ONE-HOP RETRIEVAL

从问题到场景，再到直接知识

当前主流程只读取场景阶段直接引用的知识，不递归检索后续节点。最终回答仍由你的 Agent 基于原文组织。

  1. 匹配场景
  2. 取直接引用知识
  3. 检索原文段落
  4. 核对依据与评价

提交问题后，依次查看候选场景、直接知识、原文证据和可继续探索的路径。每次提交都会保存运行记录。
