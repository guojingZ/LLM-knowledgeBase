#  个体进化的底层逻辑-从知识到技能，从技能到方法论

原创  何明璐  [ 人月聊IT ](javascript:void\(0\);)

__ _ _ _ _

在拿到刘润老师的《底层逻辑》这本书后，我没有习惯性地从头开始阅读，而是首先阅读了个体进化的底层逻辑这个章节。

整体的阅读感受就是可读性很好，将很多道理讲的浅显容易理解，让人容易一口气读完。至少我读完后不看书本能够清楚地记忆住。

#  **从人生商业模式谈起**

![](https://mmbiz.qpic.cn/mmbiz_png/mqhc3Xuogv4xuuBe0LQjSwLgGpBjWTiapiaFsHVT28znuTuZEws54WtXb7C3AHMmWF8y5mYqbfsuehxc2EwXnAWQ/640?wx_fmt=png)

在书里面提出了一个很重要的概念，即人生商业模式，给出如下公式。  

人生商业模式=能力*效率*杠杆

同时书里面还对时间管理中的时间颗粒度，从边际成本角度来考虑做产品还是服务，人脉的本质是平等交换；个体进化的三要素知识，技能和态度等做了详细阐述。

这些内容实际在我写的思维和自我管理和成长的文章中都有涉及，但是没有像刘润老师书本内容一样演绎得如此好。将复杂的东西讲解来他人很容易理解。

所有的道理都是对的，但是你依然过不好这一生。

对于个体进化的道理也一样，不是简单的思维和意识的转变就可以，而是需要长期的实践。因为书里面一开始就给出了人生商业模式的基础能力，能力依靠的是可怕的勤奋。

如果你没有成功，因为你连基本的勤奋都没有做好。当我思考到这里的时候，发现一个问题，就是有多少人能够做到可怕的勤奋，又有多少人能够做到按5分钟，10分钟来分解自己的时间颗粒度？

当我们无法做到这些点的时候，我们如何完成个体进化？

正如我多年前在时间管理上谈到的一个观点。

>
> 每个人都不是机器人，无法做到完全的时间精确，那么你要做的就是真正提升你做事情的效率，当你做事效率高的时候，你自然会节约出别他人更多的时间，那么你花费一些时间休闲娱乐又有什么问题呢？

#  个体进化的底层逻辑究竟是啥？

就个人理解，个体进化的底层逻辑本质是  快速的事物认知和学习力，并通过学习实践后将其转变为个人技能和经验模式的能力。

个体进化的底层逻辑是  基于某个专业领域的深度积累，并能够懂得如何兼顾其他知识领域知识将自己专业领域能力规模化复制或快速放大的能力。

个体成长本身就是一个认识世界和改造世界的过程。

你进化得快简单来说就是你遇到的事情，经历的环境比别人多，在这个过程中你不断学习实践，不断提升自我技能，同时将技能转变为自我经验。

学习实践和复盘，并将三者融会贯通形成闭环，以持续改进的能力  。才是个体进化的底层逻辑。学习是基础，实践是必不可少的过程，而复盘是完成最终的经验提炼。

当然，所有的进化最终还是要为价值创造服务。

那么这个价值创造来说一定需要你有一个围绕自己专业领域的基础能力。

基础能力是本，否则谈效率和杠杆没有意义。

但是酒香也怕巷子深，因此个体进化的第二次逻辑是快速的融合外部其他知识域知识，外部资源和人脉。  一个是跨领域知识的融合能力，一个是人脉和资源的连接能力
。也就是进化第二阶段的重点是如何整合资源放大自己的能力，和书里面谈到的杠杆是一个道理。

要放大自己的能力。

一个是你可以将个人经验显性化，形成知识库+方法论，教会给你的同事，从个体运作变成团队运作。另外一个是你要从服务到产品，尽量做零边际成本的事情，减少个体在服务上的时间损耗。

#  个体进化的本质-在群体中进化

最近2到3年，我自我感觉个人能力实际提升得很慢，一个很大的原因就是最近和外在的交流减少，同时也没有现场去参与一下实际的大型项目的咨询和建设工作。

类似咨询服务。

虽然边际成本很高，需要现场人员投入支撑，也无法规模化复制。但是一个最大的好处就是增加了你的现场实践经验，也增加了你的群体观察能力。

你咨询一个公司不一定能得出一些有用的结论。

但是  你将你咨询服务的多个公司相关的需求，遇到的问题进行群体观察，那么你就能够总结出更加普遍适用的规律或方法论。

这个规律就是这类咨询服务的底层逻辑。

这个和我前面谈事物认知的时候谈到认知升级的一个关键点是思路一样的。

即一个人的认知提升一定要从单一的事物认知，问题解决，过渡到对群体的观察和抽象。这种群体观察
来源于自我驱动的周期性深度复盘，最终形成认知的底层逻辑和方法论。

你仅仅研究你自己没有用。

一个封闭的自我个体研究无法让你完成个体进化过程。

个体的进化本质是来源于群体，将你放入到一个群体，一个环境中，你不断的学习实践，不断的解决问题，才能够真正完成进化过程。

你会去观察他人的优点哪些可以借鉴和模仿，你也会去观察他人的缺点和错误自己需要去避免，当然你也可以总结多个人的做事方式和行为，糅合一个适合自己的问题处理逻辑。

所有的这些都无法脱离群体。

因此个体进化的本质是  跳出个体，在群体中完成自我进化  。

#  个体进化的底层逻辑-从知识到技能，从技能到方法论

![](https://mmbiz.qpic.cn/mmbiz_png/mqhc3Xuogv4xuuBe0LQjSwLgGpBjWTiap0LCdosyfysHHTSD0qZFeicITCbpN1zEFdWv8eVe8icefibiaedGTSvibwKg/640?wx_fmt=png)

简单来讲，个体进化的底层逻辑应该是一个人能够将知识转变为技能，将技能转变为经验的快速迭代和持续改进能力。  

这个能力也可以理解为  思维能力和独立分析和解决问题的能力  。

个体进化过程就是  不断学习去认识自然，不断实践去改造自然，不断复盘去提升自我方法论的闭环过程。

学习实践复盘三者缺一不可。

书里面提的是一个人一生重要的三件事，即知识，技能和态度。在这里我将其理解为学习，实践和复盘。学习对应到知识形成，实践对应到技能形成，而复盘对应到自我方法论形成。

万法归一。

形成某一个领域的特定方法论，你自己做事的套路才是自我进化的底层逻辑。

你的学习力和模仿力强，那么一定比别人进化得快。其次，你的复盘能力强，那么一定会提升你下次做事情的效率。

个体进化的底层逻辑本质就是最终  形成自我经验方法论  。这个方法论就是知识索引，普适性的规律，让你具备以不变应万变的能力。

#  效率和时间

![](https://mmbiz.qpic.cn/mmbiz_png/mqhc3Xuogv4xuuBe0LQjSwLgGpBjWTiapxKYaicehh0f8ohiamqD2obu3e85kcqjpZib87ZibEImlDwwBC9zpFv7BjA/640?wx_fmt=png)

首先谈下如何提升效率？  

大家提得最多的就是类似刻意练习和持续精进，通过持续迭代过程来不断提升效率。而我原来谈过一个关键点供大家参考，即：  将做事过程中重复的东西自动化，  将
不重复的东西抽象出共性参数模板化。

而对于时间管理，时间颗粒度是一个很好的概念。

但是大部分人还没有到需要将你的时间管理细化到类似5分钟，10分钟这种粒度。你能够细化到每天的工作计划，任务安排就已经很不错了。

原因是啥？

你的时间并没有你想象的那么值钱。

那问题实际就转化成了不是刻意去做时间管理，争分夺秒地利用好所有的碎片化时间，而是要考虑如何提升你的单位时间价值，你提升你的个人能力。

那么效率和时间什么关系？

对于每个人来说时间都是公平的，无法延长，每天有效时间就是8+8小时，你再怎么去利用工作外的8小时时间也是有限的。

![](https://mmbiz.qpic.cn/mmbiz_png/mqhc3Xuogv4xuuBe0LQjSwLgGpBjWTiapuVQF4R3SJfhtr6wEkemQBchiapcRqS3VFFQxQZFg6smnZ3Npx6VBblg/640?wx_fmt=png)

那么你一定考虑的是通过空间换时间，而空间就和效率有关系。  

效率一个方面是提升自我生产率，通过生产率的提升来换取时间的节约。其次就是要将自己的经验转变为知识库和方法论，将服务转变为零边际成本的产品，扩大连接和传播，从而达到空间换时间的目的。

正如书里面谈到的正态分布和幂等分布。但是你要注意的是虽然幂等分布的长尾理论下，边际成本基本为零，但是你也将遭遇到更多更加强大的竞争。

有时候采用服务模式反而更好的保持自己的差异化竞争力。
