# 研究发现

## 判据与格式
- 场景：文章真正回答的“如何……”问题，有触发情境和目标产出；每篇0–3个。
- 概念：思维方法、认知原理或分析操作，须能写出 IPO 或拆成2–6步；每篇3–8个。
- 实体：具体人物、工具、产品、书籍、组织、具名框架模型；每篇2–8个。
- define 不超过50字，尽量采用原文核心措辞，只说明“是什么”。
- sources 必须写实际读过的 `raw/完整文件名.md`。
- 批次内 id 不重复，跨批次不去重；第一轮不展开 IPO。
- 输出依次为处理文件、候选场景、候选概念、候选实体、存疑项五部分。
- 示例措辞简洁、定义聚焦本体；概念 type 与实体 category/type 严格使用 rubric 枚举。
