概念建模 · 三种方式对比

IPO模型（原子性） · Decomposition模型（组合性） · Hybrid混合模型 · 概念-实体边界判定

IPO模型 · 原子性概念

  • • 自身足够原子化，不需要拆解为其他概念
  • • 用 ipo 字段建模：input → process → output
  • • process.steps 至少1步，完整有序的操作序列
  • • 适用: 第一性原理、归纳、演绎、抽象

Decomposition模型 · 组合性概念

  • • 由多个子概念协同完成的方法/框架
  • • 用 decomposition 字段: step → uses (concept://)
  • • 至少2步(仅1步说明不需要分解)
  • • 适用: 深度思考、架构思维、解决问题流程

Hybrid混合模型

  • • 既有核心IPO，又引用子概念完成特定步骤
  • • ipo表达自身加工逻辑，decomposition表达外部组装
  • • 一个概念用哪种方式取决于其内容特征
  • • 适用: 知识体系构建、结构化思维
